# Device-frame assets

The iMac, iPad Pro, iPhone X, and Samsung TV transparent PNGs in this folder
come from [Pixelsign HTML5 Device Mockups](https://github.com/pixelsign/html5-device-mockups).
They are used as non-interactive artwork over the live application iframes.

The upstream project is MIT licensed. Its license and source-art credits are
preserved alongside the files as `LICENSE.txt` and `CREDITS.txt`.
