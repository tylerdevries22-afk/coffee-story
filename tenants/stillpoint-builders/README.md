# Stillpoint Builders tenant pack

This folder is the committed build-input mirror for the Stillpoint Builders
franchisor tenant. Elevate stores the canonical numbered revision; the
`.tenant-pack.json` ownership record binds the files materialized here.

The tenant installs the commerce catalog for consultations, renovation
packages, and warranty visits, plus construction operations and workforce
training. `app-store/` remains generated output and is not part of the authored
tenant pack.
