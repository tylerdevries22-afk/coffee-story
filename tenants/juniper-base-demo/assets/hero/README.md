# Hero media

The customer app's home-screen hero: a short looping video and the stills that
back it.

- `home-hero.mp4` — the hero loop. H.264 MP4, a few seconds, muted (it plays
  without sound). Keep it small; it ships inside the app bundle.
- Stills (poster frames, section art) as `.webp` — e.g. `stones.webp`.

Portrait sources render best on the phone hero. Nothing here may carry another
product's branding (docs/DO-NOT-RESEMBLE.md).
